**An Android coursework app for exploring movie lists and details.**

Developed during classes guided by [Mr **Lebranchu**](https://github.com/rlebranchu) for the
**Semester 7 of Android Development module** part of my engineering degree at **IMT Atlantique**, in
preparation for the module assessment.

<br>

## Features

- Browse titles, directors, and ratings.
- Open a movie's details with type-safe navigation.
- Load remote data, with local movie samples as a fallback.

## Run locally

1. Clone this repository and open it in **Android Studio**.
2. Install **SDK 37**, configure your local SDK path, and sync Gradle.
3. Run `app` on an emulator or device with **Android 10+ (API 29)**.

The Gradle daemon configuration requests **JetBrains JDK 25**.
